# Grilling

Resolve consequential decisions and their prerequisites before treating a proposal as agreed.

Map the open decisions internally as a tree. Ask only questions whose prerequisites are settled; do not ask the user to choose downstream details that depend on unanswered questions.

Gather facts from the environment yourself. Delegate bounded factual investigations when subagents are available and independent work can continue; otherwise investigate locally. An investigation is an unsettled prerequisite only for questions that depend on its result.

Ask a manageable round of independent questions, each with a concise recommendation and the trade-off that matters. Follow the user's preferred pace, including one question at a time. Use the host's question tool when appropriate, or ordinary conversation when unavailable. Wait for answers before deciding dependent matters. Do not treat silence as agreement.

Reuse facts and decisions already established. Distinguish necessary choices from routine details the agent can resolve within the user's intent. Stop exploring branches that cannot materially change the outcome.

When the relevant decisions are settled, summarize the agreed proposal and any remaining uncertainty. If the user asked only for discussion, stop there. Implement only within existing authorization; ask for a decision only when a material choice or permission remains missing. Do not impose a redundant final confirmation after the user has already authorized the work.

This skill does not itself authorize writes. Documentation may be updated during the discussion when the user authorized that scope; otherwise present draft text.
