# Platformer findings

Phase 1 and Phase 2 implementation evidence. Browser playthrough is still unverified: no browser
was connected to this session. No engine defect was reproduced or engine code changed.

| #   | Area                        | Symptom                                                                                                                                                                          | Classification     | Evidence (test or code)                                                                     | Resolution                                                                                                  |
| --- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 1   | Candidate readiness         | Synchronous scene systems cannot prepare a replacement; the host prepares it after rendering and the authority system polls for readiness.                                       | Missing capability | `transitions.ts`: `reconcile`; `game.ts`: transition authority; delayed-respawn test        | Implemented host bookkeeping; input to NGNE-7                                                               |
| 2   | Candidate lifetime          | Game owns prepared handles, but speculative preparations are not associated with the requesting scene's lifetime. The host tracks instance ownership and releases stale results. | Missing capability | `transitions.ts`: owner ID, `clear`, late-result release                                    | Registry tested through replacement, completion, restart, late delivery, stop and disposal; input to NGNE-7 |
| 3   | Camera initialization       | Setup must position the camera before the engine's no-argument mount cut. | 4   | Tile collision              | One-way crossings, solid side bounds, spikes and the fall-out line need explicit game rules.                                                                                     | Game mechanics     | Collision and controller tests in `tests/platformer.test.ts`                                | Implemented in the example; no engine change needed                                                         |
