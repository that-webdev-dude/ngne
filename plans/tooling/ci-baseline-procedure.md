# Frozen CI baseline procedure

The [baseline record](ci-cost-baseline.json) is explicitly incomplete. Empty measurements are not zero-cost runs, a denominator or budget compliance. Hosted execution and consumer agreement are separate gates.

The original reviewed draft [ci-baseline.workflow.yml](ci-baseline.workflow.yml) retains the frozen verification steps, uses an exact frozen checkout, disables deployment by removing both showcase publication and the deploy job, and allows only manual dispatch. The draft remains inactive. The installed [measurement workflow](../../.github/workflows/ci-baseline.yml) adds a bootstrap push trigger restricted to `tooling/t1a-coverage-ownership` and its own workflow path, plus manual dispatch. Merging it into `main` does not trigger baseline execution. It has read-only repository permissions and no deployment or Pages publication. The ordinary verification/deployment workflow remains unchanged. Artifact names include the attempt number so reruns preserve earlier evidence. Original workflow bytes and their SHA-256 remain fixed in the baseline record. The draft adds a 30-minute hang guard and environment logging; all original verification commands and failure-injection checks remain. Setup-node retains the original Node 24/npm-cache configuration. The original consumer coverage is retained because this is the old baseline.

Publication and five hosted measurements were authorized on 2026-09-23. Execution procedure:

1. Publish the installed workflow on the existing feature branch. The scoped push starts the first complete attempt without requiring a default-branch workflow installation. Use the Actions full-run rerun endpoint for later deliberate attempts; never rerun only failed jobs. Record `(runId, attempt)` as the unique measurement identity. All attempts use the same workflow revision and exact frozen checkout. Do not dispatch the original workflow on main.
2. Record the measurement branch revision and workflow hash, verifying the checkout pin, frozen Git blob hash and absence of deploy/pages-upload jobs. Execute five deliberate successful complete attempts sequentially; record every failed attempt too. A fresh hosted job is required for each measurement; attempts of the same immutable workflow run are separate measurements, never duplicate samples from one execution. Do not replace a slow successful run. If the 30-minute guard proves insufficient, record the explicit adjustment and retain failed attempts.
3. Fetch run/job metadata and every step timestamp (excluding queue time), setup-node cache-hit logs, runner-image/version and Node/npm/Chrome versions from logs. Record actual cache state for every run; matching final runs must reproduce the condition sequence. Do not label the first run cold without evidence of a cache miss. Retain the baseline's original verification artifact upload, record each artifact's ID/name/size and total uploaded bytes through the Actions API. Preserve failure artifacts.
4. Fill successfulRuns/failedAttempts using the required fields in the record. Stage entries include name, conclusion, start/end and absolute seconds. Artifact entries include ID/name/bytes. Store raw API/log provenance beside the recorded timings. Compute the median only once five successful measurements exist. Do not infer zero seconds for missing timestamps.
5. Final acceptance needs five matched runs, a required-coverage old-to-new stage map, absolute stage/wall durations and artifact sizes, and median growth at most the proposed 20%. Rebaseline if environment/cache drift prevents matching. Consumer removal is a scope change, not an engine speedup; record explicit compatibility cost separately.

Authenticated Git and Actions API access were verified using the existing Git credential without displaying or persisting it. `gh` is not required. Raw API metadata and job logs must be retained before requesting each next attempt because default API endpoints otherwise report only the latest attempt. Baseline-dependent delivery/cost acceptance remains blocked until five successful measurements are recorded.
