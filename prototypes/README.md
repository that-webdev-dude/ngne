# Historical prototypes

`ngne/v00/` is the frozen integrated audit candidate, including its tests,
audit record and promotion hashes. It is historical evidence, not a second
supported engine. Current production files may differ from this snapshot.

Use and change `src/`, `demo/` and `tests/` at the repository root. Do not
backport fixes into v00. The supported behavior is described in
[the implementation contract](../docs/contracts/NGNE.md).

The [v00 audit](ngne/v00/AUDIT.md) records the original validation process.
Its results and hashes describe that promotion, not later releases.
